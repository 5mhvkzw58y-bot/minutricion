# Daily Nourish · Planner

Aplicación web estática de planificación nutricional semanal, en español, con estética minimalista y adaptable a móvil.

## Funciones
- Navegación semanal y calendario con mes/año.
- Cinco momentos de comida al día: desayuno, almuerzo, comida, merienda y cena.
- Menú de recetas equilibradas con estimación orientativa de proteína por ración.
- Botón para cambiar individualmente cualquier comida.
- Recetas con ingredientes, tiempo aproximado y preparación.
- Check individual por comida y control de día completo.
- Resumen semanal y mensual de cumplimiento.
- Guarda menús modificados y checks en el navegador (localStorage).

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub (por ejemplo `daily-nourish`).
2. Sube `index.html` y `README.md` a la raíz del repositorio.
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona `main` y `/ (root)` y guarda.
6. Espera a que GitHub Pages publique la URL.

Los datos se guardan localmente en el navegador/dispositivo. No existe sincronización entre dispositivos ni cuenta de usuario.
